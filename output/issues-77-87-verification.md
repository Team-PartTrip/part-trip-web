## 검증 근거

- `npm test`: 99/99 통과. 날짜·알림 링크/분류·시도 집계·좌표 없는 사진의 수동 위치 반영을 포함합니다.
- `npm run build`, `npm run lint`, `git diff --check`: 통과.
- `tests/issues-77-87.browser.mjs`: 별도 로컬 브라우저의 통제된 모의 API에서 24개 확인 항목 통과. API 요청 본문을 검사했습니다.
- 별도로 동행 선택 → 나머지는 기본 → 일정 생성까지 정확히 3회 클릭을 확인했습니다.
- 375px 달력의 가로 넘침과 날짜/배지 겹침이 없는 것을 수치로 확인했습니다.
- 기존 브라우저 회귀 검사 3개 통과: 일정 기준, 오류·재시도·사진 코멘트·경로 대기, 멤버 사진·일일 개수 보존.
- 로그인된 Chrome의 실제 서버 데이터를 읽어 로컬 수정본을 확인했습니다. 실제 플래너를 새 탭의 ID 주소로 열어 제목·확정 상태·단계 숨김을 확인했습니다.
- 실제 서버의 사진 0장 기록에서 빈 상태와 사진 추가만 표시됨을 확인했습니다.
- 실제 서버 여행카드의 크기는 420×523px였습니다.

## 검증 경계와 남은 기능

- 실제 계정의 생성·사진 업로드·사진 위치 변경은 수행하지 않았습니다. 해당 쓰기 동작은 모의 API에서 요청 내용을 검증했습니다.
- #79 최초 대안은 원안 구현 완료가 아니었습니다. 후속 SDK 구현을 추가했지만 지도 서비스 활성화 전까지 실제 지도 완료로 판정하지 않습니다.
- #86 주소 변환을 추가하고 실패 시 좌표 이름 저장을 차단했습니다. 실제 외부 서비스 성공 검증은 아직 완료하지 않았습니다.
