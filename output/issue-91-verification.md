# 이슈 #91 검증

## 반영

- 선택한 시니어의 최신 위치를 10초마다 조회합니다.
- 기록 지도와 같은 카카오 지도 SDK 로더를 사용합니다. 위치 변경 시 Marker.setPosition과 Map.setCenter만 호출하고, 좌표가 같으면 호출하지 않습니다.
- 마지막 확인 시각 옆에 방금 전 / N분 전을 표시하며 화면을 열어둔 동안 1분마다 재계산합니다.
- 앱이 꺼져 있어도 약 20초마다 전송된다는 안내를 반영하고 12시간 삭제 안내를 유지합니다.
- 빈 위치는 기존 문구·지도 숨김을 유지하고 SDK 실패 시 외부 지도 링크를 유지합니다. 재시도와 잘못된 좌표·시각 처리도 제공합니다.
- 데스크톱에서 지도 영역이 지나치게 좁아지지 않도록 시니어 상세 카드가 한 행을 사용합니다.

## 검사

- 단위 테스트 105개, 빌드·린트 통과.
- `tests/issue-91.browser.mjs`: 실제 카카오 SDK·타일을 사용한 브라우저 확인 항목 10개 통과.
- 공개 시험 좌표를 바꾸고 실제 10초 주기로 새 위치를 받는 것을 확인했습니다. SDK 생성자를 관찰하여 지도·마커 각각 1개를 유지하고 핀·중심만 이동하며 같은 좌표 재조회 시 이동 호출도 없는 것을 검사했습니다.
- 지도 중심은 SDK 화면 투영·픽셀 정렬 오차를 허용합니다. 마커 위치는 1e-8도 이내, 지도 중심은 1e-4도 이내로 검사합니다.
- 1분 뒤 상대 시각 갱신 검사는 별도 가상 시계를 사용합니다. 위치 10초 갱신 검사는 시간을 단축하지 않았습니다.
- 빈 위치, SDK 오류 후 링크 유지, 실제 SDK 재시도, 375px 가로 넘침을 검사합니다.
- 앱 데이터 API는 모의 응답이며 계정 데이터·실제 사용자 위치를 쓰거나 바꾸지 않았습니다. 실제 iPhone의 백그라운드 전송 → 서버 → 보호자 계정까지의 종단 검증은 수행하지 않았습니다.
- 기본 작업 폴더의 이전 캡처 5개는 기존 사용자 작업으로 보존했습니다.
